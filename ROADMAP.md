# Roadmap

El lab on-premises es la fase 1. Las siguientes siguen el temario del máster.

| Fase | Contenido | Módulo | Estado |
|---|---|---|---|
| 1 | Red enrutada Debian (Kea, nftables), dominio AD DS, clientes W11 | M1-M3 | ✅ v0.1 |
| 2 | **Bastionado** del lab: SSH por clave y sin root, firewall de filtrado (no solo NAT) en los routers, política de contraseñas fuerte, revisión de permisos | M2-M3 | Pendiente |
| 3 | **Híbrido con Azure**: red virtual conectada por VPN, identidad híbrida (Entra ID) | M4, M7 | Pendiente |
| 4 | **Infraestructura como código**: la parte cloud con Terraform y despliegue con GitHub Actions, con escaneo de seguridad del código IaC | M9 | Pendiente |
| 5 | **Monitorización y detección**: recogida de logs de routers y DC | M5-M8 | Pendiente |

El alcance definitivo se cerrará con el profesorado.
